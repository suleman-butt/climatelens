How ClimateLens works

ClimateLens turns everyday weather measurements into a forecast for tomorrow. It shows how a machine-learning service can run reliably and automatically, from data collection to the page you are reading.

  1. 1Collect

    Every day, ClimateLens downloads the latest measurements from the German Weather Service (DWD) from {{ station_count }} weather stations serving {{ cities | length }} cities: temperature, wind, humidity, air pressure, cloud cover, rain and sunshine. {% if about and about.records %}So far it holds {{ "{:,}".format(about.records) }} daily records covering {{ about.years }} years of weather, since {{ about.start | nice_date }}.{% endif %}

  2. 2Learn

    {% if about and about.served_models == ['lightgbm'] %}A machine-learning model called LightGBM studies this history. It combines hundreds of small decision rules, each capturing a pattern such as “a clear, calm evening after a cold day often brings frost”. {% else %}A machine-learning method studies this history and learns how today's weather relates to tomorrow's.{% endif %}

  3. 3Forecast

    For tomorrow, it looks at today's weather, the last few days and the time of year, and applies the patterns it learned. Before use it was tested on past days it had never seen, {% if about and about.served_models == ['lightgbm'] %}and it beat simple rules such as “tomorrow will be like today” and “the usual weather for this time of year”. {%- else %}and the most accurate method was chosen.{% endif %}

  4. 4Stay up to date

    New measurements arrive every day, so the forecast is refreshed daily. Once a month the model is retrained on everything collected so far, and the most accurate method is kept. {% if about and about.trained_on %}Last trained on {{ about.trained_on | nice_date }}.{% endif %}
